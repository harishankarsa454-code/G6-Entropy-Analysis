Experiment · sample size

Small samples under-report entropy.

A sample of N bytes can hold at most N different values, so its entropy can never pass log₂ N. Perfectly random data only reaches 8 bits once there are far more than 256 bytes to count.

Limitations

A high number is not a verdict.

Entropy describes the distribution of symbols. It says nothing about keys, algorithms or order. These four cases are measured on your current input.

All calculations run in Python on this computer. Nothing is sent anywhere else. H = −Σ p(x) · log₂ p(x), measured over byte values
